Ambos file debe tener el mismo sistema de coordinación (crs). Aqui usamos el crs=9311 que es el sistema de usado por “US National Altlas Area projection (USGS)”.

CRS EPSG:2163

Its non-deprecated replacement EPSG:9311 will be used instead

us_states_9311 = st_transform(us_states, 9311)

north_carolina_9311 = st_transform(north_carolina, 9311)

Necesitamos el contorno de los estados de los EEUU para poder hacer el mapa de PR. El contorno de los estados de los EEUU se puede obtener usando el paquete spData y la función st_union().

north_carolina_9311_bb = st_as_sfc(st_bbox(north_carolina_9311))
